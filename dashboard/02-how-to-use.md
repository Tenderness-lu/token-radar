# How to use this radar

1. Sort the board by Farm net EV, not by implied value: the headline value is what a token might be worth, the net EV is what a farm is worth after its costs.
2. Read the worked example first: one protocol priced term by term, so you can see what the model actually does with a TVL.
3. Open a row's detail view: the model terms, the recompute check, the launch odds and the ten-step farm plan with its costs.
4. Read the farm plan before acting: capital, hold time, net expected value — and that only a slice of it would ever reach one wallet.
5. Check the protocol's own points page from its official docs before claiming; never pay to claim, never connect your wallet from a DM or a search ad, and farm from one wallet only.
