# How to use this radar

1. Sort by Farm net EV, not implied value: the headline is what a token might be worth, the net EV what a farm is worth after costs.
2. Read the worked example first: one protocol priced term by term, so you can see what the model actually does with a TVL.
3. Open a row's detail view: model terms, recompute check, launch odds, ten-step farm plan with costs.
4. Read the farm plan before acting: capital, hold time, net expected value — only a slice would ever reach one wallet.
5. Check the protocol's own points page from its official docs before claiming; never pay to claim, never connect from a DM or a search ad, and farm from one wallet only.
